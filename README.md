# Hi

This is a personal project to house a website, as well as serve as a point to hook into various personal projects and experiments I'll make with the Elixir ecosystem.

## Movie night

`/movie-night` is available to logged-in users; `/admin/movie-nights` is admin-only. An admin creates a night, friends nominate films, and the admin locks nominations. Friends spend up to three votes (one per film). Admins close voting to reveal the winner.

Movie details come from [The Movie Database (TMDB)](https://www.themoviedb.org/).
